# Biology Samples

Creature fragments recovered from the field and analyzed at the [[Bio Lab]]. **Bio Orders request them by name.** Every creature leaves five fragment types, one per biome (Frozen / Coastal / Geothermal / Volcanic / Deep), sharing an id prefix and a rarity tier.

## Legendary fragments

**Glacial Wyrm** (`gw_`): Cranial Plate (Frozen) · Caudal Fin (Coastal) · Cardiac Node (Geothermal) · Jaw Fang (Volcanic) · Spinal Vertebra (Deep)

**Spire Drake** (`sd_`): Cranial Crest (Frozen) · Wing Membrane (Coastal) · Obsidian Scale (Geothermal) · Tail Club (`sd_tail_barb`, Volcanic) · Talon (Deep)

## Rare fragments

**Vault Crab** (`vc_`): Dorsal Carapace (Frozen) · Mandible Claw (Coastal) · Antenna Cluster (Geothermal) · Walking Leg Joint (`vc_walking_leg`, Volcanic) · Eye-Stalk (Deep)

**Tidal Cephalopod** (`oc_`): Cranium (Frozen) · Tentacle Arm (Coastal) · Chitin Beak (Geothermal) · Ink Sac (Volcanic) · Camera Lens Eye (`oc_lens_eye`, Deep)

**Bone Walker** (`bw_`): Skull (Frozen) · Foreclaw (Coastal) · Ribcage Segment (`bw_ribcage`, Geothermal) · Hindlimb Bone (`bw_hindlimb`, Volcanic) · Tail Spike (Deep)

**Vent Drifter** (`vd_`): Bell Membrane (`vd_bell`, Frozen) · Nematocyst Ring (`vd_nematocyst`, Coastal) · Neural Mesh (Geothermal) · Photophore (Volcanic) · Trailing Tendril (`vd_tendril`, Deep)

**Hive Sentinel** (`hs_`): Mandible (Frozen) · Forewing Membrane (`hs_wing_membrane`, Coastal) · Thorax Plate (Geothermal) · Abdomen Segment (Volcanic) · Compound Eye (Deep)

**Hollow Choir** (`hc_`): Aperture Lip (Frozen) · Shell Whorl (Coastal) · Septum Plate (Geothermal) · Hooked Beak (`hc_beak`, Volcanic) · Tentacle Crown (Deep)

**Ferric Sea-Lily** (`fs_`): Calyx Plate (Frozen) · Arm Segment (Coastal) · Stalk Columnal (Geothermal) · Oral Tegmen (Volcanic) · Holdfast Rootlet (Deep)

**Crustal Echo** (`ce_`): Stalked Eye (Frozen) · Swimmeret Lobe (Coastal) · Mouth Disc (Geothermal) · Great Appendage (Volcanic) · Cephalic Photophore (Deep)

## Uncommon fragments

**Mycelial Husk** (`mh_`): Fruiting Body (Frozen) · Spore Pod (Coastal) · Mycelium Root (Geothermal) · Chitin Node (Volcanic) · Stigmatic Disc (Deep)

**Mantle Strider** (`ms_`): Chelicera (Frozen) · Leg Tarsus (Coastal) · Pedipalp (Geothermal) · Abdomen Sclerite (Volcanic) · Eye Cluster (Deep)

**Glasswing Mantis** (`gm_`): Prismatic Eye (`gm_compound_eye`, Frozen) · Folded Wing (Coastal) · Raptorial Claw (Geothermal) · Abdominal Sheath (Volcanic) · Antennal Whip (Deep)

**Veil Mantle** (`vm_`): Cephalic Horn (Frozen) · Wing Sheet (Coastal) · Gill Filament (Geothermal) · Tail Barb (Volcanic) · Ventral Photophore (Deep)

## Common fragments

**Magmatic Annelid** (`ma_`): Cranial Papilla (Frozen) · Cuticle Molt (Coastal) · Ganglion Node (Geothermal) · Chitinous Seta (Volcanic) · Luminous Ring (Deep)

**Salt Tortoise** (`st_`): Scute Plate (Frozen) · Plastron Shard (Coastal) · Limb Claw (Geothermal) · Beak (Volcanic) · Carapace Neural Plate (`st_carapace_neural`, Deep)

Ids follow `<prefix>_<fragment>` in snake case (e.g. `gw_cranial_plate`, `st_scute_plate`); where the id differs from the display name it is noted above.
