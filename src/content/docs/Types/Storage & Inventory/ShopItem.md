One catalogue entry. **Returned by:** `shop.get_catalogue()`

| Member | Returns | Meaning |
| --- | --- | --- |
| `.id` | string | Item id (used for buying) |
| `.name` | string | Display name |
| `.cost` | number | Price in credits |
